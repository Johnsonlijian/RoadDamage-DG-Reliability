# Manuscript-Facing Derived Tables

This directory contains compact, non-sensitive CSV tables exported for the current manuscript traceability layer.

Included tables cover:

- RDD2022 domain inventories and label-boundary counts;
- ordinary mixed-domain versus leave-one-domain-out summaries;
- YOLOv8s source-domain budget-sweep summaries;
- domain-level and per-class diagnostic audits;
- Faster R-CNN MobileNetV3-320-FPN detector-family check results;
- RetinaNet ResNet50-FPN detector-family check results;
- RT-DETR-L transformer-family check results;
- confidence-threshold and decision-frontier summaries.

These files are derived outputs only. They do not redistribute raw RDD2022 archives, extracted images, full prediction exports, active manuscript drafts, cover letters, reviewer-response drafts, or internal project rounds/logs.
